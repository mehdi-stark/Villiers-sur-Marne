# Scripts de départ (à copier/adapter dans chaque projet dès la 1re session)

| Script | Rôle | Le skill qui l'attend |
|---|---|---|
| `capturer.mjs` | captures multi-écrans desktop/mobile + détection de débordement (playwright) | `audit-app`, `audit-vitrine` |
| `mesurer-demande.mjs` | largeur d'intention par pays via l'autocomplétion Google (gratuit) | `analyse-marche` |

Ils remplacent les placeholders `<outillage>` des skills. Un script de collecte
de revue (`revue-hebdo`) dépend du schéma du projet : le modèle est celui de
l'usine ecom (`packages/core/scripts/revue-hebdo.mts`).
