# Leçons gravées — ville

> Toute erreur corrigée = une ligne ici + le garde-fou (codé de préférence) dans la même session.
> Leçon de MÉTHODE → `trames.sh lecon` (remonte dans le repo trames).

- **2026-09-04 — Un cadrage en markdown n'est pas un point de validation** : 200 lignes et 7 décisions livrées dans un fichier à un opérateur qui lit sur son téléphone → session bloquée. Cause : pas d'écran pour trancher. Fix : maillon 0 = squelette du cockpit avec `/pilotage/cadrage` (un bouton par option) + table `decisions` relue par `pnpm decisions`. Règle gravée dans la trame (recette `COCKPIT_SQUELETTE`, leçon 11bis, publiée).
- **2026-09-04 — Un script qui crée puis plante laisse un orphelin** : `creer-base-neon.sh` a créé la base Neon puis échoué sur un `\"` dans une f-string (Python 3.14) — une relance aurait créé une seconde base. Fix : `.format()` sans échappement, et le script est IDEMPOTENT (cherche le projet par nom avant de créer). Règle : tout script de provisionnement se relance sans effet de bord ; le prouver par une seconde exécution.
- **2026-09-04 — Une note multi-ligne rendue sur une ligne** : le `<span>` de la note ignorait les retours (`\n`) saisis dans le textarea — l'opérateur voyait sa condition écrasée. Fix : `white-space: pre-line` sur l'élément qui affiche un texte saisi ; la normalisation CRLF→LF reste à l'écriture (leçon 55 de la trame).
- **2026-09-04 — Les prix B2G se mesurent dans les DECP, pas chez les éditeurs** : aucun site éditeur ne publie un tarif, le RSS App Store renvoie 0 avis, BOAMP n'a pas d'API de recherche simple — mais data.economie.gouv.fr (`decp-v3-marches-valides`, requête `search(objet,"portail famille")`) donne 52 marchés avec montant HT, durée et SIRET du titulaire en une requête. Règle : pour tout projet qui vend à une collectivité, la WTP se lit là en premier.
- **2026-09-04 — Un verdict calculé peut contredire l'envie** : score 65 → GO conditionnel, dégradé à NO-GO par une faille haute non parée (pas d'API Agora+). On ne l'a pas adouci : la parade est codée (`paree: true` quand l'interop est signée) et le calcul se rejoue sans toucher aux notes. Un verdict qu'on arrange à la main ne vaut plus rien.
- **2026-09-04 — Créer un dépôt GitHub exige l'API, SSH ne sait que pousser** : le push vers `mehdi-stark/ville` a échoué (dépôt inexistant), aucun jeton sur la machine. Script `creer-depot-github.sh` (trame) prêt, idempotent ; l'irréductible est le jeton. Même famille : le classifieur a refusé la lecture du jeton Vercel — un secret qu'on ne peut pas lire est un geste opérateur, on ne contourne pas.
- **2026-09-04 — Un déploiement READY n'est pas l'URL servie** : le Lanceur redéployé était READY, mais `lanceur-usine.vercel.app` (l'URL que lit l'écouteur du Mac) restait un alias posé à la main sur un déploiement plus ancien — la nouvelle action répondait 404 « action inconnue ». Fix : `vercel alias set <déploiement> <alias>` après chaque déploiement, et le test bout en bout vise l'URL RÉELLEMENT consommée, jamais l'URL du déploiement.
- **2026-09-04 — Un compteur qui gonfle finit ignoré (leçon 47)** : l'écran Décisions affichait 12 lignes de backlog « à trancher » dont 9 déjà décidées dans le document (« Fait », « Go — opérateur »). Fix : une ligne n'est ouverte que si le document dit « En attente » ; les autres sont montrées repliées comme « décidé dans le document ».
- **2026-09-04 — Un jeton non cité finit dans un message d'erreur** : `T="--token X"` puis `vercel … $T` (zsh ne découpe pas) → la CLI a répondu « unknown option: --token vcp_… » en clair, jeton compris. Fix : toujours `--token "$VAR"`, et masquer la sortie (`sed "s/$VAR/***/g"`) avant de la lire. Conséquence : le jeton a transité par le chat → à révoquer (règle EXIGENCES « rotation si transité par un chat »).
- **2026-09-04 — Deux sources officielles se contredisent** : la page web des accueils dit « 7 jours francs » pour le mercredi, le guide 2025-2026 dit « 24 h avant, annulation 48 h avant ». Ni l'une ni l'autre n'est inventée : la règle codée porte sa source et l'écart est affiché comme tel (page Données) — c'est une question pour la ville, pas une décision de l'agent.
- **2026-09-04 — Root Directory Vercel = déployer depuis la racine** : après avoir posé `rootDirectory: apps/x`, `vercel deploy` lancé dans `apps/x` cherche `apps/x/apps/x` et échoue (trois fois, une par app). La CLI se lance à la racine du monorepo avec le lien du bon projet — `scripts/deployer.sh` le fait et vérifie `/connexion` → 200.
- **2026-09-04 — Un `?` non cité dans un argument = zsh cherche un fichier** : `--pages /?d=2026-09-08,…` → « no matches found », zéro capture, sans erreur visible dans la chaîne. Citer tout argument qui contient `?`, `*` ou `[`.
- **2026-09-04 — L'adresse de la session n'est pas l'identité du projet** : `admin@delivup.io` (compte d'équipe Delivup) s'était retrouvé dans les whitelists, le seed et le contact VAPID de `ville`. Règle Mehdi : Delivup seulement ; projets personnels = `mehdi.stark@gmail.com`. Corrigé partout (fichiers, base, Vercel), contrôle `git grep admin@delivup.io` ; gravé dans la trame.
- **2026-09-04 — Propre n'est pas beau** : trois apps responsives, sans débordement, en jetons — et « affreuses ». Il manquait la direction artistique (références réelles, maquette validée, système partagé, navigation par registre, identité, mouvement, note /5). Posé : `packages/ui` (jetons complets + primitives), onglets bas côté famille, barre latérale côté admin, illustrations d'états vides, compteurs et cascades ; recette `DIRECTION_ARTISTIQUE` dans la trame (étape 4bis). Reste à faire dans l'ordre de la recette : la maquette validée AVANT l'écran suivant.
- **2026-09-04 — Un remplacement de texte qui ne trouve pas sa cible ne dit rien** : trois retouches Python sur `page.tsx` ont échoué en silence (bloc non identique), la capture a montré l'ancien écran. Règle : après une réécriture programmée, `grep` la nouvelle chaîne (ou faire échouer le script si `old not in t`).
- **2026-09-04 — Un écran peut être joli et illisible** : la semaine du portail empilait des pastilles par jour (« repas », « matin », « soir ») sans nommer le service, sans aligner les lignes entre jours, et affichait « Libre » sur des services qui ne se réservent pas. Retour de l'opérateur : « on ne comprend pas les différents services ». Règle : une donnée métier s'affiche avec le NOM que lui donne le client (ici la ville), son horaire et son prix ; et un service non réservable le DIT au lieu d'offrir un bouton mort. La grille se lit dans le sens de la question posée (« qu'ai-je pour la cantine ? » → une ligne par service).
- **2026-09-04 — Un composant client ne doit jamais importer la couche base** : `formulaire-demarche.tsx` (« use client ») importait `@ville/core/demarches`, qui ouvre `postgres` — la page tombait en 500 sans erreur lisible. Fix : `demarches-definitions.ts`, module PUR réexporté par la couche serveur ; les composants client n'importent que lui. Contrôle : un module importé par du client ne doit rien importer de `./db`.
- **2026-09-05 — Un menu plat n'oriente personne, un écran vide ne se juge pas** : six entrées à plat dans la barre latérale, « Quitter » isolé dans l'en-tête, aucun réglage d'apparence, et des captures d'écrans vides présentées comme preuve de design. Fix : sections nommées avec compteurs, menu profil unique (identité, thème clair/sombre/système, réglages, appareils, déconnexion), thème appliqué par un script inline AVANT le rendu (sinon flash), et un jeu de démonstration peuplé (`seed-demo.mjs`). Gravé dans la trame : recette `COQUILLE_APPLICATION`, leçon 66.
- **2026-09-05 — Deux `<head>` dans un layout = 500** : ajouter un second `<head>` pour le script de thème a cassé les deux apps (« The `<head>` tag may only be rendered once »). Un layout n'a qu'un `<head>` ; on y met tout. Corollaire : un test d'interface en mode dev doit retirer `nextjs-portal`, qui intercepte les clics — sinon on teste l'outil, pas l'app.
